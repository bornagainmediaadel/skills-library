SKILLS LIBRARY — MASTER INDEX
=============================

1045 unique skills from 33 source repositories, organised into 19 category folders.
Every category folder has a README.txt describing each skill inside it.
Open 'Skills Search.html' to search all skills in plain English and filter by category.

FOLDERS
-------
  01 Marketing & Growth  (49 skills)
      Skills for planning and running marketing: paid ads, social media, content, PR, launches,
      competitor research, analytics and growth loops. Start here when you want more customers
      or more attention for a product.
  02 SEO & Web Visibility  (15 skills)
      Skills for getting found on Google and AI search engines: SEO audits, schema markup, site
      structure, programmatic SEO, metadata fixes, domains and llms.txt files.
  03 Sales, Funnels & Conversion  (20 skills)
      Skills for turning visitors into leads and buyers: sales funnels, landing page conversion
      audits, CRO, signup and onboarding flows, offers, lead magnets, referrals, cold email and
      churn prevention.
  04 Writing, Copy & Communications  (47 skills)
      Skills for writing and editing words: marketing copy, emails, documentation, READMEs,
      changelogs, meeting minutes, internal comms and long-form articles. Also includes de-AI-
      ifying prose.
  05 Design, UI & UX  (72 skills)
      Skills for designing interfaces that look and feel premium: design systems, UI polish,
      animation and motion, accessibility, Stitch/Figma workflows, taste/anti-slop guides and
      mobile design.
  06 Brand & Creative Assets  (14 skills)
      Skills for brand identity and visual assets: brand kits, logos, banners, social carousels,
      book covers, themed artwork and on-brand visual documents.
  07 AI Image, Video & Audio  (60 skills)
      Skills that generate media with AI: images (GPT Image, FLUX, Nano Banana, Qwen), video
      (Veo, Seedance, Higgsfield), voice and music (ElevenLabs), avatars, podcasts, upscaling
      and editing.
  08 Documents, Slides & Files  (27 skills)
      Skills for producing and converting files: Word, PowerPoint, Excel, PDF, HTML
      presentations, diagrams and markdown conversions.
  09 Frontend & Web Development  (40 skills)
      Skills for building websites and web apps: React/Next.js patterns, performance, Core Web
      Vitals, browser testing with Playwright/DevTools, TypeScript and web quality audits.
  10 Backend, Cloud & Infrastructure  (96 skills)
      Skills for servers, APIs and cloud: Cloudflare Workers, Vercel, AWS, Kubernetes, Docker,
      CI/CD pipelines, observability, microservices and backend patterns in Node, Python, Go and
      Java.
  11 Payments & E-commerce  (16 skills)
      Skills for taking money online: Stripe (integration, Connect, upgrades, apps), PayPal,
      billing automation, pricing, paywalls, PCI compliance and Shopify.
  12 Data, Databases & Analytics  (93 skills)
      Skills for data work: SQL and PostgreSQL, vector databases (Qdrant, Pinecone), RAG, ML
      training and evaluation, data pipelines, dashboards and Oracle-to-Postgres migrations.
  13 Security & Compliance  (34 skills)
      Skills for keeping systems safe: security reviews, threat modelling, OWASP, secrets
      management, GDPR, MCP/agent security audits and hardening.
  14 Software Engineering Practices  (135 skills)
      Skills for how code gets written well: debugging, test-driven development, code review,
      git workflows, refactoring, planning-to-code discipline and language-specific best
      practices (Python, Rust, Go, Java).
  15 AI Agents, Skills & Automation  (148 skills)
      Skills about building and running AI agents: creating skills, MCP servers, Claude Code
      plugins and hooks, LangChain/LangGraph, subagent orchestration, memory, prompt engineering
      and the inference.sh toolkit.
  16 Research, Planning & Productivity  (54 skills)
      Skills for thinking before doing: research workflows, specs and PRDs, task breakdown,
      planning files, daily focus boards, interviews that sharpen ideas and learning/teaching.
  17 Microsoft, Azure & Power Platform  (93 skills)
      Skills for the Microsoft ecosystem: Azure, .NET and C#, Power BI, Power Platform and Power
      Automate, Dataverse, Copilot, Semantic Kernel, TypeSpec and Visual Studio Code extensions.
  18 Business Strategy & Operations  (23 skills)
      Skills for running the business: go-to-market strategy, pricing, investor communication,
      financial models, startup metrics, market sizing, team design and hiring.
  19 Games, 3D & Specialist Scripting  (9 skills)
      Skills for niche creative tooling: game engines (Unity, Godot, Minecraft), shaders, CAD
      scripting (FreeCAD, Rhino), Adobe Illustrator automation and electronics mockups.
