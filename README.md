# Skills Library

1045 AI agent skills (Claude Code / Cowork / Codex / Cursor-style `SKILL.md` folders) collected from 33 open-source repositories and organised into 19 categories.

**Search it:** open [`Skills Search.html`](Skills%20Search.html) in a browser (or the hosted copy at quickaquotes.au/skills) and type what you want to do in plain English.

**Use a skill:** copy its folder into `.claude/skills/` in a project (or `~/.claude/skills/` for all projects). Each category folder has a `README.txt` describing every skill inside.
